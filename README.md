# バスのりばパズル

駐車場のバスを出す順番を考えて、色ごとに並んだ人を乗せていく渋滞パズル。

## あそびかた

1. 下の駐車場で、矢印の先があいているバスをタップ
2. バスが「のりば」に停まる
3. 列の先頭から、同じ色の人が乗る。満員になったら発車

のりばが全部うまって、先頭の人が乗れなくなったら負け。
ちがう色のバスは、その色の人が先頭に来るまでのりばをふさぐ。バスの数字は乗れる人数。

## レベル

- 全60面。どの面も解ける手順があることを確認済み
- レベル1〜10はのりば3台、11からは4台
- 4面から列が輪になり、6面からななめのバス、12面からいろんな角度のバスが出る
- 41〜60面は「ぎっしり」面。47〜100台の小さなバスが駐車場に詰まっていて、人の列も長い
- 61面以降は51〜60面の左右反転と色替え

## こまったとき

- **ヒント**：今の盤面から解ける手順を計算して、次に出すバスを光らせる。使うと★がひとつ減る
- **メニュー → お手本を見る**：その面を最初から自動で解いて見せる。お手本はクリアに数えない
- **メニュー → このレベルをとばす**：次の面に進む。とばした面は「きろく」から後で遊べる

## ホーム画面に置く（iPhone）

Safariでページを開いて、共有ボタンから「ホーム画面に追加」。

## セーブと記録

進み具合と、面ごとの記録（★・ベストタイム・もどした回数）は、そのブラウザの中に保存される。「きろく」ボタンで一覧が見られて、クリア済みの面にはそこから飛べる。

★は、もどさずクリアで3つ、1回もどして2つ、2回以上で1つ。

- `manifest.webmanifest`, `icon-*.png` — ホーム画面用のアイコンと設定
